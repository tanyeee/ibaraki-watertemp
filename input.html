水温を記録する

登録用トークンの設定

初回だけ、所有者（tanyeee）のGitHubアカウントで専用トークンを発行してください。

  1. Fine-grained tokenの作成画面を開く。
  2. Resource ownerは「tanyeee」、Repository accessは「Only select repositories」で「ibaraki-watertemp」だけを選ぶ。
  3. Repository permissionsの「Issues」を「Read and write」にする。Contentsなど他の書き込み権限は不要です。
  4. 有効期限を設定して発行し、下に貼り付ける。期限が切れたら再設定してください。

保存先はこのブラウザ内です。公開コードには保存しません。同じサイトのスクリプトからは読み出せるため、共有端末では保存しないでください。

使い方
  1. 初回だけ登録用トークンを設定します。
  2. 日付と水温を入力して「登録」をタップすると、この画面から送信されます。
  3. 「受付完了」が表示されたら、数分後に自動処理でグラフへ反映されます。同じ日付の値は上書きされます。
